Winterberry Holly — photo files

Drop files into this folder with these exact names. Nothing else
needs to change in the code -- each one lights up on the card
automatically as soon as it's here.

  cover.jpg   The card's default face (front cover). A 2D render of
              the 3D model, once that's ready.

  1.jpg       Identifying photo #1 -- Unlobed leaves with many
              small teeth.
  2.jpg       Identifying photo #2 -- No thorns.
  3.jpg       Identifying photo #3 -- Berries grow close to the
              twig on very short stalks.
  4.jpg       Identifying photo #4 -- Fruit is bright red.
  5.jpg       Identifying photo #5 -- Small black dot at the tip.

Any of these can be missing -- the card just shows a "coming soon"
placeholder in its place until the file shows up. .jpg or .png both
work (just keep the extension consistent with the filename above,
or tell Claude if you'd rather standardize on .png).

You can delete this file once the folder is full.

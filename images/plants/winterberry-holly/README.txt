Winterberry Holly — photo files

Drop files into this folder with these exact names. Nothing else
needs to change in the code -- each one lights up on the card
automatically as soon as it's here.

  cover.jpg   The card's default face (front cover). A 2D render of
              the 3D model, once that's ready.

Identifying photos:

  1) Unlobed leaves with many small teeth.
     Photo: 1.jpg
     Via: https://www.uwgb.edu

  2) No thorns.
     Photo: 2.jpg
     Credits: Peter M Dziuk. Via: https://www.minnesotawildflowers.info

  3) Berries grow close to the twig on very short stalks.
     Photo: 3.jpg
     Via: https://www.cvtslandscape.com

  4) Fruit is bright red.
     Photo: 4.jpg
     Via: https://blog.davey.com

  5) Small black dot at the tip.
     Photo: 5.jpg
     Credits: Gary Fewless. Via: https://www.uwgb.edu

Info sources (used for identifying this plant overall, not tied to
any one photo):
  - https://www.minnesotawildflowers.info/shrub/winterberry
  - https://extension.umd.edu/resource/winterberry-holly/
  - https://blog.davey.com/do-i-have-a-winterberry-holly/
  - https://www.uwgb.edu/biodiversity-old/herbarium/shrubs/ilever01.htm

Any of these can be missing -- the card just shows a "coming soon"
placeholder in its place until the file shows up. .jpg or .png both
work (just keep the extension consistent with the filename above,
or tell Claude if you'd rather standardize on .png).

You can delete this file once the folder is full.

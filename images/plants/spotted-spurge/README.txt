Spotted Spurge — photo files (ACTIVE pair — this one IS in the
walk's rotation now, see `active: true` on the purslane-spurge pair
in index.html)

Drop files into this folder with these exact names once you have them.
Nothing else needs to change in the code -- each one lights up on the
card automatically as soon as it's here.

  cover.jpg   The card's default face (front cover). A 2D render of
              the 3D model, once that's ready.

Identifying photos:

  1) Plant grows close to the ground, forming a spreading mat.
     Photo: 1.jpg
     Via: https://weedid.missouri.edu

  2) Leaves are dark green, slightly hairy, and often have a maroon spot.
     Photo: 2.jpg
     Via: https://weedid.missouri.edu

  3) Leaves are oval to oblong, thin, and may have finely toothed edges.
     Photo: 3.jpg
     Credit: Peter M Dziuk. Via: https://minnesotawildflowers.info/flower/spotted-spurge

  4) Stems are thin, hairy, and pink to maroon.
     Photo: 4.jpg
     Credit: Susan Mahr. Via: https://hort.extension.wisc.edu/articles/spotted-spurge-chamaesyce-euphorbia-maculata/

  5) Produces tiny, inconspicuous pinkish-white flowers.
     Photo: 5.jpg
     Credit: Peter M Dziuk. Via: https://minnesotawildflowers.info/flower/spotted-spurge

  6) Broken stems release milky white sap.
     Photo: 6.jpg
     Credit: Melody. Via: https://davesgarden.com

Info sources (used for identifying this plant overall, not tied to
any one photo):
  - https://hort.extension.wisc.edu/articles/spotted-spurge-chamaesyce-euphorbia-maculata/
  - https://minnesotawildflowers.info/flower/spotted-spurge
  - https://www.poison.org/articles/keep-away-from-spurge-sap-222

In-game "Foe" caveat: "The white sap irritates the skin, and if
ingested can cause vomiting and diarrhea"

Any of these can be missing -- the card just shows a "coming soon"
placeholder in its place until the file shows up. .jpg or .png both
work (just keep the extension consistent with the filename above, or
tell Claude if you'd rather standardize on .png).

You can delete this file once the folder is full.
